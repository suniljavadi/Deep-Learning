# Deep Learning Practice

**Status: Learning project**

Notebook-based exercises covering introductory deep learning, simple neural networks, fully connected networks, convolutional neural networks, and recurrent neural networks. The repository includes notebooks, exported PDFs, and small assignment archives; it does not include a packaged application or deployment.

## Contents

| Area | Evidence in repository |
| --- | --- |
| Foundations | `intro/` learning material |
| Feed-forward models | `Simple Neural Network/`, `Fully Connected Neural Network/` |
| Computer vision | `Convolutional Neural network/` with MNIST notebook |
| Sequence models | `Recurrent Neural Networks/` notebook |

## How To Explore

Open the `.ipynb` files in Jupyter Notebook, JupyterLab, or VS Code. The repository does not include a dependency manifest or a single supported application entry point, so the exact environment should be chosen per notebook.

## What It Demonstrates

- Notebook-based model experimentation
- Neural-network concepts across feed-forward, convolutional, and recurrent architectures
- Reading and explaining exported notebook results

## Limitations

This is an educational collection. Dataset provenance, hyperparameter tracking, reproducible training environments, automated tests, benchmark metrics, and deployment packaging are not standardized across the notebooks.

## Future Improvements

- Add per-notebook requirements and dataset instructions.
- Record model configurations and evaluation metrics consistently.
- Add a small shared utility layer and reproducible training commands.
